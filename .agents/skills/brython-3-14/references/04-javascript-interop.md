# Javascript interop

A Brython page runs in the same Javascript context as the page's other scripts; the `javascript` module and `browser.window` bridge the two.

## Loading Javascript

- Include any library with a plain `<script src="..."></script>` — its globals become attributes of `window` (e.g. `window.jQuery`)
- `browser.load(url)` — load a library at runtime with a blocking Ajax call; use it when a `<script>` tag cannot be added. Its globals are available on `window` afterwards
- `javascript.import_js(url, alias=...)` — import a Javascript module that defines a global `$module` object; its attributes become the module namespace
- `javascript.import_modules([urls...], callback)` — import ES modules; when all are loaded, `callback` is called with one module object per url (used e.g. with three.js)

```python
import javascript
javascript.import_js("js_test.js", alias="js_module")
assert js_module.x == 1
```

## Using Javascript objects from Python

- Javascript objects surface as instances of `javascript.JSObject`
- JS constructors via the `new` attribute: `Date.new(2012, 6, 10)`, `Number`, `String`, `RegExp` (Javascript regex syntax — not Python's)
- `javascript.JSON.stringify(obj)` / `JSON.parse(s)` — serialize dicts/lists/strings, parse a JSON string
- `javascript.Math`
- `javascript.NULL` and `javascript.UNDEFINED` to test for JS null / undefined
- `javascript.py2js(src)` — the Javascript code generated by Brython for a Python source string
- `javascript.this()` — the Brython object behind the JS `this`; useful inside Javascript framework callbacks

```python
from javascript import Date, RegExp, String

date = Date.new(2012, 6, 10)
print(date.toDateString())

re = RegExp.new(r"^test(\d+)$")
print(String.new("test33").search(re))    # String is required to pass a JS regexp
```
